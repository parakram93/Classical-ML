# Classical-ML
Classical ML fundamentals: regression, classification, ensembles, and unsupervised learning, implemented from scratch through to a real-world churn prediction project.

A structured walkthrough of classical machine learning, built while backfilling fundamentals after starting with neural networks first.

## Notebooks

- `data_preprocessing.ipynb` — Encoding, feature engineering, missing values
- `evaluation.ipynb` — Regression & classification metrics
- `regression.ipynb` — Linear, Ridge, Lasso, Elastic Net, SGD
- `classification.ipynb` — Logistic Regression, KNN, Naive Bayes, SVM, Decision Trees, Random Forest, XGBoost
- `unsupervised.ipynb` — K-Means, Hierarchical Clustering, PCA
- `bias_variance_tradeoff.ipynb` — Underfitting, overfitting, and tuning every model's hyperparameters
- `mini_project.ipynb` — Combined project on the Telco Customer Churn dataset

## Mini Project

Full pipeline on [Telco Customer Churn](https://www.kaggle.com/datasets/blastchar/telco-customer-churn): preprocessing → EDA → PCA/K-Means clustering → regression (Monthly Charges) → classification (Churn) → live prediction demo.

## Tools

Python, pandas, NumPy, scikit-learn, XGBoost, matplotlib
